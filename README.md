# XMZZUZHI Wiki

基于 [VitePress](https://vitepress.dev/) 构建的组织知识库文档站点。

## 快速开始

```bash
# 安装依赖
pnpm install

# 启动开发服务器
pnpm dev

# 构建静态文件
pnpm build

# 预览构建结果
pnpm preview
```

## 项目结构

```
├── .vitepress/          # VitePress 配置
│   └── config.mts       # 站点配置文件
├── docs/                # 文档目录
│   └── guide/           # 指南文档
├── index.md             # 站点首页
└── package.json
```
