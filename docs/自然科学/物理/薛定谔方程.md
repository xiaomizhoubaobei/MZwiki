# 薛定谔方程

薛定谔方程是量子力学的基本方程，由奥地利物理学家埃尔温·薛定谔于 1926 年提出。

## 数学形式

### 含时薛定谔方程

$$i\hbar\frac{\partial}{\partial t}\Psi(\mathbf{r},t) = \hat{H}\Psi(\mathbf{r},t)$$

### 定态薛定谔方程

$$\hat{H}\psi(\mathbf{r}) = E\psi(\mathbf{r})$$

## 物理意义

薛定谔方程描述了量子系统的波函数如何随时间演化，是量子力学的核心方程。
