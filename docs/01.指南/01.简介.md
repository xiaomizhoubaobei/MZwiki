# 简介

欢迎来到 **XMZZUZHI Wiki**！ 🎉

这是一个基于 [VitePress](https://vitepress.dev/) 构建的知识库文档站点，旨在为团队提供一个高效的知识管理和文档协作平台。

## 特性

- **📝 Markdown 驱动** — 使用 Markdown 编写文档，简洁高效
- **🎨 美观主题** — VitePress 默认主题，开箱即用
- **🔍 内置搜索** — 支持全文搜索，快速找到需要的内容
- **⚡ 极速构建** — 基于 Vite，开发和构建速度极快
- **🌐 多语言支持** — 支持中文本地化配置

## 如何贡献

1. Fork 本仓库
2. 创建你的特性分支 (`git checkout -b feature/AmazingFeature`)
3. 提交你的更改 (`git commit -m 'feat: 添加某项功能'`)
4. 推送到分支 (`git push origin feature/AmazingFeature`)
5. 创建一个 Pull Request

## 技术栈

- [VitePress](https://vitepress.dev/) — 静态站点生成器
- [Vite](https://vitejs.dev/) — 下一代前端构建工具
- [Vue 3](https://vuejs.org/) — 渐进式 JavaScript 框架
