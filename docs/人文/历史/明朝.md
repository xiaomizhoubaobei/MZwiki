# 明朝

明朝（1368年—1644年）是中国历史上最后一个由汉族建立的大一统王朝。

## 基本信息

- **建立时间**：1368 年
- **开国皇帝**：朱元璋（明太祖）
- **都城**：南京（初期）、北京（永乐迁都后）
- **灭亡时间**：1644 年

## 重要事件

- **靖难之役**：朱棣夺取皇位
- **郑和下西洋**：七次远航，传播中华文明
- **永乐大典**：中国古代最大的百科全书
- **土木堡之变**：明英宗被俘

## 文化成就

- 小说繁荣：《三国演义》《水浒传》《西游记》
- 科技发展：宋应星《天工开物》
- 建筑艺术：紫禁城、天坛
