# 主题配置

本文档介绍 Teek 主题的基本配置方法。

## 基本信息

本 Wiki 使用 [vitepress-theme-teek](https://github.com/teek14/vitepress-theme-teek) 作为主题，基于 VitePress 构建。

## 配置文件

主题配置位于 `.vitepress/config.mts`，主要包括：

- **站点信息**：标题、描述、语言等
- **导航栏**：顶部导航菜单
- **侧边栏**：文档目录结构（自动生成）
- **搜索**：内置全文搜索
- **站点分析**：字数统计与阅读时间预估

## Teek 主题特性

当前项目已启用以下 Teek 特性：

| 特性 | 说明 |
|------|------|
| 站点分析 | 字数统计、阅读时间预估 |
| 侧边栏样式增强 | `tk-sidebar.css` |
| 目录栏样式增强 | `tk-aside.css` |
| 文章淡入效果 | `tk-doc-fade-in.css` |
| 标题渐变色 | `tk-doc-h1-gradient.css` |
| 容器样式增强 | `tk-container.css` |
| 导航栏增强 | `tk-nav.css` |
| 表格样式美化 | `tk-table.css` |
