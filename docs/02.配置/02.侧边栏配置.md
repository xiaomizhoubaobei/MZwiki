# 侧边栏配置

本文档介绍 Teek 主题侧边栏的多级嵌套分类配置方法。

## 自动生成（推荐）

使用 `vitepress-plugin-sidebar-resolve` 插件，按文件夹层级自动生成侧边栏。

### 目录结构

按层级建好文档目录，使用数字前缀控制排序：

```
docs/
├── 01.指南/
│   ├── 01.简介.md
│   └── 02.快速开始.md
└── 02.配置/
    ├── 01.主题配置.md
    └── 02.侧边栏配置.md
```

### 配置方式

在 `.vitepress/config.mts` 中引入插件：

```ts
import { defineConfig } from "vitepress"
import Sidebar from "vitepress-plugin-sidebar-resolve"

export default defineConfig({
  vite: { plugins: [Sidebar()] },
})
```

插件会自动读取 `docs/` 目录下的文件结构，生成多级嵌套侧边栏，支持无限层嵌套（建议不超过 5 层）。

## 手动配置嵌套

也可以在 `sidebar` 配置中用 `items` 手动嵌套：

```ts
sidebar: {
  "/自然科学/": [
    {
      text: "物理",
      items: [
        { text: "力学", link: "/自然科学/物理/力学" },
        { text: "光学", link: "/自然科学/物理/光学" },
      ]
    }
  ]
}
```

## 排序技巧

- **数字前缀**：文件名用 `01.xx.md`、`02.xx.md` 前缀，Teek 会自动排序并去掉序号
- **frontmatter 排序**：使用 `sidebarSort` 字段指定数字排序

```md
---
sidebarSort: 1
---
```
