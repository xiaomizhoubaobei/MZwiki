# 🤝 VitePedia 贡献指南（CONTRIBUTING）

欢迎来到 **VitePedia**！

这是一个基于 **VitePress + Teek + Lumen** 构建的个人百科 / 知识库。

本指南将帮助你快速、安全地参与贡献。

---

## 一、我能贡献什么？

✅ 新建词条
✅ 完善现有词条
✅ 修正错误（事实 / 格式 / 内链）
✅ 优化结构（标题 / 标签 / 分类）
❌ 删除已有词条（除非确认废弃）
❌ 破坏 Frontmatter 规范

---

## 二、准备工作（只需一次）

### 1️⃣ Fork & Clone

```bash
git clone https://cnb.cool/XMZZUZHI/wiki.git
cd wiki
pnpm install
```

### 2️⃣ 启动本地预览

```bash
pnpm dev
```

浏览器访问：

http://localhost:5173

---

## 三、创建新词条（标准流程）

### ✅ Step 1：检查是否已存在

先在站内搜索：

```
[[你想创建的词条]]
```

如果是 **红链（红色 + ?）** → 可以创建 ✅

---

### ✅ Step 2：新建文件

目录必须遵循规范：

```text
docs/
└─ 自然科学/
   └─ 物理/
      └─ 量子力学.md
```

---

### ✅ Step 3：填写 Frontmatter（必须）

```yaml
---
title: 量子力学
category: 自然科学
tags: [物理, 量子理论]
author: 你的名字
date: 2026-05-18
---
```

⚠️ **不要手写**：
`wordCount`, `readingTime`, `lastUpdated`
（由插件自动生成）

---

### ✅ Step 4：编写正文

```md
# 量子力学

量子力学是描述微观粒子行为的物理学理论。

## 历史发展
## 基本理论
## 应用领域

参见 [[薛定谔方程]]。
```

---

### ✅ Step 5：提交 PR

```bash
git checkout -b add-quantum-mechanics
git add .
git commit -m "add: 量子力学"
git push origin add-quantum-mechanics
```

然后在 CNB 平台发起 Pull Request。

---

## 四、完善现有词条

### ✅ 可接受修改

- 补充内容
- 增加内链
- 修正事实错误
- 优化标签 / 分类

### ❌ 不建议修改

- 词条标题（会破坏内链）
- 删除已有内链
- 大幅重排结构（除非必要）

---

## 五、标签与分类规范（非常重要）

### 分类（category）

- 一级分类，数量少
- 示例：`自然科学 / 人文历史 / 工程技术`

### 标签（tags）

- 多个
- 更细粒度
- 示例：`物理 / 量子理论 / 科学史`

⚠️ 新增标签前，请确认：

- 是否已有语义相近的标签？
- 是否真的有必要？

---

## 六、内链规范（维基语法）

✅ 使用：

```md
[[量子力学]]
[[薛定谔方程|波函数方程]]
```

❌ 禁止使用：

```md
[量子力学](/wiki/量子力学)
```

原因：

- 无法生成反向链接
- 无法 Redlink Tracker
- 无法图谱可视化

---

## 七、图片与资源

- ✅ 放在 `public/images/`
- ✅ 文件名语义化
- ✅ 使用相对路径引用

```md
![薛定谔方程](/images/schrodinger-equation.svg)
```

---

## 八、提交信息规范（Commit Message）

请使用 **语义化提交**：

| 类型 | 说明 |
|---|---|
| `add:` | 新增词条 |
| `update:` | 更新内容 |
| `fix:` | 修复错误 |
| `refactor:` | 结构调整 |
| `docs:` | 文档 / 规范 |

示例：

```text
add: 量子力学
update: 补充量子力学历史部分
fix: 修正薛定谔方程公式
```

---

## 九、常见问题（FAQ）

### ❓ 词条标题写错了怎么办？

✅ 正确做法：
1. 新建正确标题的词条
2. 将原词条内容迁移过去
3. 在原位置留下重定向（或删除）

❌ 直接重命名文件（会破坏内链）

---

### ❓ 词条内容太多怎么办？

✅ 拆分成子词条：

```md
# 量子力学
参见 [[量子力学的数学基础]]
```

---

### ❓ 不确定分类怎么办？

✅ 先放入最接近的父分类
✅ 在 PR 中说明，由维护者调整

---

## 十、维护者说明（Maintainer）

如果你是仓库维护者，请确保：

- ✅ 所有 PR 符合 Frontmatter 规范
- ✅ 不破坏现有内链
- ✅ 定期运行 Redlink Tracker
- ✅ 定期更新首页精选 / 时间线
