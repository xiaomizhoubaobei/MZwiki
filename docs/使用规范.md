# 📘 VitePedia 使用规范

> 本规范适用于 **VitePress + Teek + Lumen + doc-analysis** 搭建的个人百科 / 知识库。
>
> 目的：**降低维护成本、保证结构稳定、方便自动化。**

---

## 一、目录结构规范（强制）

```
docs/
├─ index.md              # 首页
├─ 标签/
│  └─ index.md           # 标签索引
├─ 待创建词条.md          # Redlink 列表
├─ 自然科学/
│  │  └─ 物理/
│  │     ├─ 量子力学.md
│  │     └─ 薛定谔方程.md
└─ .vitepress/
   ├─ config.ts
   └─ theme/
```

✅ **禁止**：

- 随意扁平堆放 md 文件
- 中文目录名（一律英文，标题用 frontmatter）

---

## 二、Frontmatter 规范（核心 · 不可妥协）

### ✅ 必填字段

```yaml
---
title: 量子力学
category: 自然科学
tags: [物理, 量子理论]
author: 张三
date: 2026-05-18
---
```

| 字段       | 说明         | 示例             |
| ---------- | ------------ | ---------------- |
| `title`    | 词条正式名称 | 量子力学         |
| `category` | 一级分类     | 自然科学         |
| `tags`     | 标签（数组） | [物理, 量子理论] |
| `author`   | 创建者       | 张三             |
| `date`     | 创建日期     | 2026-05-18       |

### ⚠️ 推荐字段（自动补全）

| 字段          | 来源          | 说明     |
| ------------- | ------------- | -------- |
| `wordCount`   | doc-analysis  | 字数     |
| `readingTime` | doc-analysis  | 阅读时间 |
| `lastUpdated` | VitePress     | 最后更新 |

---

## 三、内链书写规范（维基语法）

### ✅ 标准写法

```md
[[量子力学]]
```

### ✅ 别名写法

```md
[[薛定谔方程|波函数方程]]
```

### ❌ 禁止写法

```md
[量子力学](/wiki/量子力学)
```

原因：

- 破坏自动解析
- 无法生成反向链接
- 无法 Redlink Tracker

---

## 四、标签命名规范（决定搜索质量）

✅ **统一小写**

✅ **不使用空格，用连字符**

✅ **语义明确，不堆砌**

| ✅ 正确     | ❌ 错误                 |
| ----------- | ----------------------- |
| `人工智能`  | `AI`                    |
| `量子物理`  | `量子-物理-理论`        |
| `科学史`    | `历史-科学-中国`        |

---

## 五、词条编写规范

### 1️⃣ 开头一句话定义

```md
# 量子力学

量子力学是描述微观粒子行为的物理学理论。
```

### 2️⃣ 正文分层

```md
## 历史发展
## 基本理论
## 应用领域
## 相关概念
```

### 3️⃣ 必加项

- ✅ 至少 1 个内链
- ✅ 至少 1 个标签
- ✅ 至少一个二级标题

---

## 六、图片规范

- ✅ 放在 `public/images/`
- ✅ 文件名语义化：`schrodinger-equation.svg`
- ✅ 使用 `medium-zoom` 放大

```md
![薛定谔方程](/images/schrodinger-equation.svg)
```

---

## 七、自动化与维护规范

| 事项           | 工具             | 频率     |
| -------------- | ---------------- | -------- |
| 字数 / 阅读时间 | doc-analysis     | 每次构建 |
| Frontmatter 补齐 | auto-frontmatter | 每次构建 |
| 未创建词条     | Redlink Tracker  | 每次构建 |
| 本地搜索       | Pagefind         | 每次构建 |
| 离线访问       | PWA              | 每次构建 |

✅ **不要手动改自动生成的数据**

---

## 八、Git / 协作规范（重要）

- ✅ 一条词条 = 一次 commit
- ✅ Commit 信息清晰：

```
add: 量子力学
update: 修正薛定谔方程公式
fix: 修复内链错误
```

- ❌ 禁止一次性提交几十个词条

---

## 九、什么时候算"完成一个词条"？

✅ 满足以下所有条件：

- [ ] 有 `title / category / tags`
- [ ] 至少 1 个内链
- [ ] 至少 1 个二级标题
- [ ] doc-analysis 成功统计
- [ ] 能在搜索中被找到
